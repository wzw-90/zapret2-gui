## ✨ Возможности

- 🚀 **Полная автономность (Single Executable)**:
  Все бинарные файлы (`winws2.exe`, `WinDivert.dll`, `WinDivert64.sys`), конфигурации (`zapret2.conf`), Lua-скрипты и списки доменов встроены прямо в `.exe` файл (`ZapretGUI.exe`). При первом запуске в пустой папке приложение автоматически распаковывает все необходимые ресурсы.
- 🎨 **Современный нативный интерфейс на Rust (egui/eframe)**:
  - Мгновенный запуск и потребление памяти менее 30 МБ RAM.
  - Адаптивные карточки и гармоничная темная тема оформления.
  - Сегментированная навигация по вкладкам: *Главная*, *Списки хостов*, *Сетевой Доктор*, *Логи работы*.
- 🔔 **Умный системный трей Windows**:
  - Сворачивание при нажатии на закрытие окна (приложение работает в фоновом режиме без захламления панели задач).
  - **Динамический цвет иконки в трее**: синий в режиме ожидания, **зеленый** — при активном обходе блокировок.
  - Защита от случайных срабатываний: одиночный клик не открывает окно и меню; двойной клик разворачивает окно.
- ⚙️ **Управление Windows-службой в 1 клик**:
  - Установка и удаление системной службы `winws2` для автоматического старта при включении ПК без необходимости держать открытым графический интерфейс.
  - Нативная интеграция через Win32 Service Control Manager (SCM).
- 🩺 **Встроенный «Сетевой Доктор»**:
  - Автоматическая проверка прав Администратора, наличия драйвера и целостности компонентов.
  - Обнаружение конфликтующих сетевых утилит (Killer Network, CFosSpeed, SmartByte, ASUS GameFirst).
  - Измерение реального HTTPS-пинга до серверов YouTube и Discord.
  - Тюнинг адаптеров: отключение LSO (Large Send Offload) для устранения микрофризов.
- 📋 **Управление списками доменов и логами**:
  - Быстрый подсчет активных записей в `hosts-youtube.txt`, `hosts-discord.txt`, `hosts-general.txt`, `hosts-user.txt`.
  - Открытие любого списка или рабочей папки в проводнике Windows в один клик.
  - Встроенный просмотрщик логов движка `winws2.log` в реальном времени.

## 🚀 Быстрый старт

1. Скачайте свежий релиз `ZapretGUI.exe` со страницы [**Releases**](https://github.com/wzwyz/zapret2-gui/releases).
2. Поместите файл в любую удобную папку (например, `C:\Program Files\Zapret` или на рабочий стол).
3. Запустите `ZapretGUI.exe` (приложение запросит стандартное подтверждение прав Администратора UAC, необходимое драйверу перехвата пакетов WinDivert).
4. Выберите нужный пресет (по умолчанию **«Основной (YouTube + Discord + Сайты)»**) и нажмите **«▶ ЗАПУСТИТЬ ZAPRET2»**.
5. Для закрытия окна просто нажмите на крестик — утилита продолжит работу в системном трее рядом с часами.

## 📁 Архитектура проекта

Кодовая база полностью рефакторизована и разделена на изолированные модули:

```
zapret2-gui/
├── Cargo.toml                  # Конфигурация Cargo и оптимизации релиза (LTO, codegen-units = 1)
├── build.rs                    # Компиляция Windows-ресурсов (.ico и манифест)
├── app.ico                     # Иконка приложения
├── src/
│   ├── main.rs                 # Точка входа, самоподнятие UAC, инициализация окна eframe
│   ├── engine.rs               # Движок управления процессами winws2 и Windows-службой
│   ├── embedded.rs             # Встроенные ассеты (include_bytes!) и автораспаковка
│   ├── doctor.rs               # Диагностический модуль «Сетевой Доктор»
│   ├── cmd_utils.rs            # Утилиты скрытого выполнения процессов без мелькания консолей
│   ├── icon_32.bin             # RGBA буфер синей иконки трея (32x32)
│   ├── icon_green_32.bin       # RGBA буфер зеленой иконки активного трея (32x32)
│   └── ui/                     # Модульная UI-система (egui)
│       ├── mod.rs              # Корневой стейт ZapretApp, обработчик трея и цикл отрисовки
│       ├── components.rs       # Карточки одинаковой ширины, кастомные кнопки вкладок
│       ├── main_tab.rs         # Вкладка статуса, запуска, пресетов и службы
│       ├── doctor_tab.rs       # Вкладка диагностики сети и оптимизации
│       ├── lists_tab.rs        # Вкладка управления списками хостов
│       └── logs_tab.rs         # Вкладка просмотра логов в реальном времени
│
├── bin/                        # Бинарные файлы движка
│   ├── winws2.exe              # zapret2 x64
│   ├── WinDivert.dll           # Библиотека перехвата
│   └── WinDivert64.sys         # Драйвер ядра с официальной EV-подписью
├── config/                     # Конфигурации пресетов (zapret2.conf, etc.)
├── lists/                      # Списки доменов
└── lua/                        # Lua-скрипты десинхронизации (zapret-antidpi, zapret-auto)
```

## 🛠️ Сборка из исходников

### Требования:
- **ОС**: Windows 10/11 x64
- **Rust**: актуальная стабильная версия (1.80+), устанавливается через [rustup.rs](https://rustup.rs/)
- **Visual Studio Build Tools**: C++ x64/x86 build tools

### Команды:

```powershell
# 1. Клонирование репозитория
git clone https://github.com/wzwyz/zapret2-gui.git
cd zapret2-gui

# 2. Проверка и компиляция dev-сборки
cargo check

# 3. Сборка оптимизированного релизного бинарника
cargo build --release
```

Готовый автономный файл будет находиться по пути:
```
target/release/zapret2-gui.exe
```

## ❓ Часто задаваемые вопросы (FAQ)

<details>
<summary><b>Зачем требуются права Администратора?</b></summary>
Движок zapret2 использует драйвер <code>WinDivert</code> для анализа и десинхронизации пакетов сетевого стека на уровне ядра Windows. Операционная система Windows разрешает загрузку фильтрующих драйверов пакетов исключительно с правами локального Администратора.
</details>

<details>
<summary><b>Почему иконка в трее меняет цвет?</b></summary>
Когда обход DPI отключен, иконка отображается в стандартном синем цвете. Как только процесс <code>winws2</code> запущен и фильтрация активна, иконка становится ярко-зеленой, позволяя мгновенно видеть статус даже при закрытом окне.
</details>

<details>
<summary><b>Влияет ли утилита на пинг в онлайн-играх?</b></summary>
Нет. Правила WinDivert настроены строго на домены и порты из списков (YouTube, Discord, блокируемые сервисы). Игровой трафик (Steam, Riot Vanguard, EasyAntiCheat, Battle.net) не перехватывается и идет напрямую без задержек.
</details>

<details>
<summary><b>Как полностью удалить службу из автозагрузки?</b></summary>
Откройте вкладку «Главная», в блоке «Служба Windows» нажмите кнопку «Удалить службу».
</details>
